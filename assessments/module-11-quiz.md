# Module 11 quiz

Nine scenario questions on shipping your model: where to host the weights, licensing against the
training data's terms, public versus gated repos, revisions and tags, verifying a release from a
clean environment, choosing a $0 demo host, demo safety controls, writing a credible technical
report, and closing every paid resource and key. Pass mark: 70% (7 of 9).

Before you start, you should have finished:

- [11.1 · Publishing the model on Hugging Face](../lessons/module-11/lesson-01.md)
- [11.2 · A live demo Space](../lessons/module-11/lesson-02.md)
- [11.3 · The technical report and final cost ledger](../lessons/module-11/lesson-03.md)

The practical result of this module is your public model repos, the demo Space, `REPORT.md` and a
closed `budget.md`. The quiz checks the decisions behind them.
