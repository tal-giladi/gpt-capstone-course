# Module 1 quiz

Nine scenario questions on running a real-money ML project safely: reading the pipeline and the
budget, the spending rules and the kill checklist, choosing and scoping accounts and secrets, and
the project repo with its CPU dry run. Pass mark: 70% (7 of 9).

Before you start, you should have finished:

- [01.1 · The project, the budget and the spending rules](../lessons/module-01/lesson-01.md)
- [01.2 · Accounts, API tokens and secrets](../lessons/module-01/lesson-02.md)
- [01.3 · Your project repo and a CPU dry run](../lessons/module-01/lesson-03.md)

The practical result of this module is in your GitHub repo and your accounts: a private repo with
green tests and a resumed smoke run, `budget.md` with signed spending rules, and guardrails
switched on at every provider. The quiz checks the decisions behind them.
