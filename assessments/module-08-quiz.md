# Module 8 quiz

Nine scenario questions on evaluating your base model honestly: choosing tasks, shots and metrics
for a ~350M model, keeping harness settings identical across models, comparing models with
different tokenizers in bits per byte, reading standard errors and paired bootstrap intervals,
stating contamination, and wording claims so they match their evidence. Pass mark: 70% (7 of 9).

Before you start, you should have finished:

- [08.1 · Setting up lm-eval-harness](../lessons/module-08/lesson-01.md)
- [08.2 · Comparing against GPT-2 and your baseline](../lessons/module-08/lesson-02.md)
- [08.3 · Writing the evaluation report](../lessons/module-08/lesson-03.md)

The practical result of this module is `EVAL_REPORT.md` with the four-model table, bits per byte on
identical text, training-curve plots and a checked list of claims. The quiz checks the reasoning
behind it.
