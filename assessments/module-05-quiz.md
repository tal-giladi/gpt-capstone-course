# Module 5 quiz

Nine scenario questions on the GPT-2 124M baseline: reading the config and where its settings come
from, launching a multi-GPU run without wasting node time, checkpointing and recovering from the
failures a rented node actually has, and judging the finished run against published numbers.
Pass mark: 70% (7 of 9).

Before you start, you should have finished:

- [05.1 · The baseline config and a multi-GPU launch](../lessons/module-05/lesson-01.md)
- [05.2 · Checkpoints, resume and surviving a dead node](../lessons/module-05/lesson-02.md)
- [05.3 · Running the 10B-token baseline](../lessons/module-05/lesson-03.md)

The practical result of this module is your baseline checkpoint and log in
`ckpt/baseline_124m/`, the W&B run, your drill notes and `results.md`. The quiz checks the
decisions behind them.
