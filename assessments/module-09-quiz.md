# Module 9 quiz

Nine scenario questions on instruction tuning your own model: choosing SFT data and its license,
context length and truncation, the plain-text chat template and the assistant-only loss mask,
precision and learning rate, reading training logs, and judging a small chat model honestly.
Pass mark: 70% (7 of 9).

Before you start, you should have finished:

- [09.1 · Choosing SFT data and a chat template](../lessons/module-09/lesson-01.md)
- [09.2 · Running SFT and checking the chat model](../lessons/module-09/lesson-02.md)

The practical result of this module is your chat model in `hf/my-gpt-350m-sft/`, the data
decision in `reports/sft_data.md` and the base-vs-SFT probe report. The quiz checks the decisions
behind them.
